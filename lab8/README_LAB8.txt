Компьютерная графика. Удаление невидимых граней, Z-буфер, камера.

Запуск:
1) Все файлы архива распаковать в одну папку.
2) Установить NumPy: pip install numpy
3) Запустить main.py: python main.py

Файлы:
main.py — окно, OBJ, геометрия, матричные преобразования, камера, нормали и режимы.
zbuffer.py — реализация Z-буфера (буфер глубины и растеризация треугольников).
cube.obj, sphere.obj, utah_teapot_lowpoly.obj — демонстрационные модели.

Показ преподавателю:
1) Выберите «Куб (OBJ)» или «Чайник (OBJ)»; включите режим «Отсечение граней».
   Повращайте объект: линии граней, отвернутых от камеры, пропадают.
   «Нормали граней» отображает направления наружных нормалей стрелками.
   Для параллельной проекции можно задать направление обзора тремя числами.
2) Выберите «Перекрытие кубов» и «Z-буфер». С включенным буфером видны
   ближайшие поверхности независимо от порядка обхода. Выключение Z-буфера
   показывает перерисовку поверхностей по порядку обхода.
   Дополнительно есть сцена «Три куба в ряд».
3) Выберите «Камера» (перспектива): ЛКМ с перетаскиванием или кнопки
   вращают камеру вокруг неподвижного объекта. Колесо мыши — приближение.
   Положение и цель камеры указаны в левой панели.

Преобразования объекта:
- поворот вокруг X/Y/Z; масштабирование относительно центра;
- перенос dx,dy,dz; отражение относительно XY/YZ/XZ;
- поворот вокруг прямой по двум заданным точкам.

Ограничения учебной программы:
- Модели должны иметь корректные плоские грани, т.к. многоугольники
  для Z-буфера разбиваются на треугольники веером.
- Треугольник, пересекающий ближнюю плоскость камеры, сейчас отбрасывается
  целиком (полное геометрическое отсечение по near-plane не реализовано).
- Расчет нормалей направлением от центра наиболее надежен для выпуклых
  многогранников; для сложных OBJ иногда требуется правильный порядок вершин.
